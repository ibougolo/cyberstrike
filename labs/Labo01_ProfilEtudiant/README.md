# Laboratoire 1 - Profil Étudiant

## Description
Programme C# qui demande les informations d'un étudiant et affiche un profil formaté.

## Fonctionnalités
- Demande le prénom de l'étudiant
- Demande l'âge
- Demande le programme d'études
- Demande la ville
- Demande le nombre d'heures d'étude par semaine
- Affiche un profil formaté
- Calcule l'âge de l'année prochaine
- Calcule les heures d'étude par mois (approximativement)

## Exemple d'exécution
```
Entrez votre prénom : Alex
Entrez votre âge : 19
Entrez votre programme d'études : Informatique
Entrez votre ville : Sudbury
Combien d'heures d'étude par semaine? 8

----- PROFIL ÉTUDIANT -----
Nom : Alex
Âge : 19
Programme : Informatique
Ville : Sudbury
Heures d'étude par semaine : 8
Alex aura 20 ans l'année prochaine.
Alex étudie environ 32 heures par mois.
```

## Comment exécuter
```bash
cd labs/Labo01_ProfilEtudiant
dotnet run
```
